# صفحة هبوط لإعلانات الإشعارات الفورية (Push Notifications Landing Page)

## نظرة عامة
هذه صفحة هبوط مستجيبة (Responsive) مصممة للترويج لخدمة إعلانات الإشعارات الفورية. الصفحة متاحة باللغة العربية وتستخدم HTML و CSS وجافاسكريبت البسيط.

## الميزات
- تصميم متجاوب يعمل على جميع أحجام الشاشات
- محسّن للغة العربية مع دعم الاتجاه من اليمين إلى اليسار (RTL)
- قسم FAQ مع وظيفة الأكورديون (الطي والفتح)
- تأثيرات CSS حديثة وجذابة
- تحميل سريع بفضل استخدام SVG للرموز

## كيفية الاستخدام
1. قم بتنزيل أو استنساخ المستودع
2. افتح ملف `index.html` في متصفحك المفضل
3. يمكنك تخصيص المحتوى من خلال تعديل ملفات HTML و CSS

## هيكل الملفات
- `index.html` - الصفحة الرئيسية وهيكل الصفحة
- `styles.css` - جميع أنماط CSS
- `script.js` - وظائف جافاسكريبت للأكورديون وغيرها
- `images/` - مجلد يحتوي على الرموز والصور

## Overview (English)
This is a responsive landing page designed to promote a push notification advertising service. The page uses HTML, CSS, and basic JavaScript and features a clean, modern design optimized for conversions.

## Features
- Responsive design that works on all screen sizes
- Modern CircularStd font embedded in the project
- FAQ section with accordion functionality
- Eye-catching CSS effects with gradient backgrounds
- Fast loading thanks to SVG usage for icons

## How to Use
1. Download or clone the repository
2. Open the `index.html` file in your preferred browser
3. You can customize the content by editing the HTML and CSS files

## Font Information
The landing page uses CircularStd font with three variants:
- CircularStd-Medium.ttf - Main text with medium weight
- CircularStd-Bold.otf - Headings and emphasized text
- circular-book.otf - Regular body text

## File Structure
- `index.html` - Main page and structure
- `styles.css` - All CSS styles
- `script.js` - JavaScript functions for accordion and more
- `images/` - Folder containing SVG icons and images
- `fonts/` - Folder containing CircularStd font files
